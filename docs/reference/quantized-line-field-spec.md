# 量化线场：加载封面的技术约束

2026-10-31。此页把当前实现与已交接的数值要求整理为 Kimi 可直接使用的技术约定；不是新的视觉设计提案。加载封面的完整展示设计由用户转交的 Kimi 会话负责。Codex 维护数值场、真实加载状态及接入。

## 参考与产品边界

- 离线参考见同目录 `quantized-line-field.html`，包含参考的完整 Path2D 字符串，可独立打开；其中品牌图形只用于研究。游戏使用原创锅、办公椅、18:00 图形，不使用 Apple、Google、Tesla 标志。
- 已交接的封面方向为“18:00 离岗校准”：纸白 `#fafaf8`、灰 `#eeeeeb`、钴蓝 `#2152e7`、近黑 `#111212`，17px 卡片圆角，本地衬线标题与中文系统字体回退。禁止嵌套卡片、玻璃态、模糊和大阴影。
- 现有展示只是可运行候选。Kimi 可以独立采用、调整或替换展示，不需照着候选美化；保留已有文件或版本历史。
- 用 Canvas 量化线段表达图形，不用普通图片或 SVG 效果替代算法。检测框只是亮度场计算，不能声称接入 AI 识别。

## 固定采样与线段

1. 每幅源 Path2D 仅采样一次：300×300 临时 Canvas，黑底白形，按24单位图形坐标居中缩放。
2. 每5×5像素以 Rec.709 亮度 `0.2126R + 0.7152G + 0.0722B` 取平均，得到60×60 `Float32Array`。读取一次像素后释放临时画布，resize/DPR变化不重采样。
3. 显示60列×30段，共1800段。相邻两采样行合成一段亮度。线段端点为 butt，段间隙0.7 CSS像素。
4. 亮度阈值严格为0.12、0.42、0.89；四档宽度 `[0.38,1.12,2.28,3.8] × cell/5.25`，四档透明度 `[0.15,0.64,0.93,1]`。
5. 共享128×128固定噪声格，seed=7319，xorshift生成，平滑双线性插值；动画中不调用 `Math.random()`。

## 指针与复位

- 指针累计位移超过1.5 CSS像素触发强度1的脉冲；触控和键盘聚焦同样可触发。
- 影响半径为图形绘制宽度的1/4；径向最大位移系数25，纵向系数0.58，距离影响为二次衰减。
- 位移弹簧刚度145、阻尼19，积分子步不超过1/30秒；脉冲按 `exp(-dt*5.5)` 衰减。移开后自然复位。

## 检测框来自真实亮度场

- 将发生位移的线段双线性投影回60×60亮度场，不使用固定坐标或随机框。
- 7×7滑窗积分图求局部平均亮度；最亮值低于0.04时无框；候选至少达到最亮值的48%。
- 非极大值抑制距离16格；不足两个候选时放宽到12格；最多三个框。
- 延续上一目标的排序加分为 `0.025*exp(-distance²/128)`。新旧目标12格内匹配，保持框身份。
- 框位置弹簧刚度144、阻尼24，子步不超过1/120秒；透明度速率16。跨区换框先淡出，透明度低于0.04才换目标，避免瞬移。
- 动画中最多每0.1秒扫描一次；静态模式可立即计算一次。可用诊断接口核查采样次数、扫描次数和目标数。

## 生命周期与可访问性

- 暂停动效、系统 reduced-motion、页面后台、组件不可见/离屏、来源弹窗打开时停止装饰动画。暂停装饰不能暂停真实资源加载。
- 销毁必须取消 RAF，移除监听和观察器。原生 RAF 通过绑定正确接收者的包装调用。
- 画布物理尺寸随DPR变化，CSS尺寸独立；不重新读取源图像。检测框和触控坐标均使用CSS像素。
- 支持键盘焦点、触摸取消和来源弹窗关闭后的焦点返回。小屏进度/失败项/重试/进入按钮必须可达。

## 程序接口与所有权

以 `src/loading/types.ts` 为接口来源。`createLoadingScreen(host, callbacks)` 返回 `update(progress)`、`setVisible(boolean)`、`getDiagnostics()`、`destroy()`。

`progress.stage` 为 download / parse / textures / audio / scene / shaders / ready / error。资源数为真实已完成数与总数，只有可靠时提供bytes。失败项有id、label、message，单件重试调用 `onRetry(id)`。没有失败且ready才允许 `onEnter()`，并在点击手势内同步调用以解锁声音。不用定时器冒充进度，不在封面开始600秒倒计时。

Kimi可写 `screen.ts`、`styles.css`、`symbols.ts`、`visual/` 和独立预览/交付文档。Codex负责 `field.ts`、`canvas-view.ts`、`types.ts`、`index.ts`、真实加载器、音频与主状态。接口变更通过共享交付记录提出，不并发改同一文件。

交付记录写 `docs/kimi/加载封面交付记录.md`，说明修改文件、API变化、桌面/窄屏实看范围、失败/重试/ready以及键盘/触控/reduced-motion检查。独立预览通过不等于主游戏或公开部署验收。
