# 房间美术、装饰与标识｜独立交付

## 1. 本轮交付边界

本模块继承现有墨绿、暖灰、米白、旧木与少量黄铜的办公室语言，制作可实际接入的房间装饰，不是概念图或另一套场景风格。

- 正式模块：`src/presentation/room-decorations.ts`
- 场景内制作工具：`src/presentation/room-decoration-kit.ts`
- 独立预览：`room-decoration-preview.html`
- 预览逻辑与样式：`src/presentation/room-decoration-preview.ts`、`room-decoration-preview.css`
- 验收脚本：`scripts/verify-room-decorations.mjs`、`scripts/capture-room-decorations.mjs`
- 联系表脚本：`scripts/make-room-decoration-contact-sheets.py`
- 证据目录：`docs/kimi/verification/room-decorations/`

没有修改 `props.ts`、`visual-utils.ts`、地图生成、玩法状态或共享资源清单；没有新增共享接口变更，没有新生成付费 GLB，也没有充值或扩大付费权限。既有打印机、档案架、杯具、纸堆、文具、饮水器和纸箱均通过模型提供器复用。

## 3. 独立预览与操作

在工程根目录运行：

```sh
npm run dev -- --port 7100
```

打开：

```text
http://localhost:7100/leadership-always-right/room-decoration-preview.html
```

- 房间索引：切换十房。
- `1`：正常人物高度视角，摄像机高 1.62 m。
- `2`：标牌近景。
- `3`：家具材质近景；“墙饰材质”按钮检查软木、白板与纸张。
- `4`：房间总览。
- `Space`：开始／暂停连续巡房；左右方向键切换房间。
- “透明墙检查”：验证墙饰隐藏、落地物件保留。
- “升桌检查”：预览桌面、电脑和部门桌签同步跟随绝对桌高。

预览使用真实 `WorldDef`、正式装饰模块和本地 GLB；房间外壳是独立简化装配，不含角色、领导、完整游戏规则或真实后端，不冒充主游戏。

## 4. 正式接口与当前接入状态

```ts
const decorations = createRoomDecorations(world, {
  models: id => modelProvider(id),
  reservedColliders: existingMeasuredColliders,
});
scene.add(decorations.root);
await decorations.prepare(renderer, camera, scene);
decorations.update(state);
const diagnostics = decorations.getDiagnostics();
// 重开或退出时：decorations.dispose();
```

生命周期约定：

- `prepare()` 初始化模块纹理并编译正式组件。
- `update()` 只更新墙饰可见性、低顶附着高度与桌签高度；不逐帧创建几何、材质或纹理。
- `getDiagnostics()` 返回房间统计、跳过项、缺失模型、墙饰、实体候选、焦点和违规。
- `dispose()` 释放本模块 `VisualResourcePool`；模型源及其共享 GPU 资源仍由资产所有方管理。
- 模型仅以只读方式 `clone(true)`；源对象的位置、旋转、动画和玩法状态不被修改。

并行工作中，Codex 已在 `scene.ts` 接入本模块，旧环境使用 `dressing: false`，并通过 `physicalBounds()` 重新测量实体。这是当前代码状态，不代表本会话完成了主场景验收。后续保留这种单套装配，不能重新叠加旧 `dressRoom/roomFixture`。

碰撞责任：

- `decorationColliders` 是候选，不直接成为玩法真状态；Codex 必须在最终装配后重新实测并统一登记。
- 前台地毯有 `measureExclude`，不能进入接待柜实体 AABB；标牌、纸张和薄地毯保持纯视觉。

- 贴墙家具同时避开已预约标牌墙段，解决表单架遮挡看板下排文字的问题；缺落点会记录 `skipped`，不挪玩法对象。

## 6. 标牌、字体与低顶状态

- 公司主牌宽 4.05 m，公司名文字约 0.29 m 字身高度；指定标语约 0.18 m 字身高度。这里指字体 em 尺寸近似值，不是每个汉字的墨线盒。
- 普通房名牌约 0.11 m 字身高度；事项板主要文字约 0.10—0.14 m。
- 标牌近景设计距离约 1.65—3.85 m，墙饰材质近景约 1.45—2.16 m；实际字体使用本机 PingFang／系统中文字体的回退栈。
- 低顶候选房的墙饰顶边不超过 1.50 m，不做吊顶装饰。
- 动态低顶时，墙饰随 `pressureRooms` 与绝对 `pressureHeights` 下移，保留 0.10 m 视觉间隙；解除后回到本房间设计高度。验收测得顶边 1.50 m。
- `transparentWalls` 只隐藏相应墙饰，不隐藏落地家具、地毯、电脑或桌签。
- `deskHeights` 是绝对桌面高度，部门桌签直接跟随；不做累加。

## 9. 资源与性能提示

装饰根节点统计：436 个网格实例、115,110 个实例三角形、136 份几何、96 份材质、87 份纹理。纹理解析共享去重，三角形按实例累计；纹理内存估算约 96.57 MB，采用 RGBA × 1.333 的粗估，不是 GPU 实测显存。

独立预览整体还包含简化外壳、桌椅与电脑。最终总览样本为 593 个网格、69—222 次 draw call、19,812—71,623 个可见三角形、65 份已初始化纹理。性能边界与软件帧时间详见验证记录，不把本模块数据外推成整局性能承诺。
