## 1. 一句话与首版范围

**六点了，假装还在上班，偷偷打卡，利用领导说出口的规则逃出办公室。被拖回工位也别慌——屁股不能离开椅子，轮子可以。**

- 本次比赛只做电脑浏览器单人、一局式逃离、较近第三人称。一局最多600秒，世界时间18:00到18:10。
- 正常通关：已完成下班打卡，并在时间归零前越过任一出口外侧边界。
- 时间归零尚未离场：加班失败结局；甩锅命中领导：单独的“被炒鱿鱼”结局，不记正常通关。
- 无工时、无电脑交付任务、无必须填满的办公进度，也不记录办公秒数。电脑仅用于开场彩蛋与装忙。
- 无联机、账号、局外成长、战斗生命值、运行时大模型或听觉感知。所有关键提示均通过画面呈现。
- 有跑、蹲、跳、短时冲刺、拿放物件、推大饼、甩锅、手动灯、同事举报、种子重玩。
- 首页明确显示“多人模式 · 待开发”，禁用且不跳转假大厅。教程为三页图文与动作示意，不另建教学关。

## 2. 首页、加载与开场

首页按钮：开始上班、怎么玩、设置；另有禁用的多人待开发入口与小型鸣谢。设置提供画质档位、鼠标灵敏度、镜头反转、减弱非必要动效。首版只有一种普通难度。

流程：轻量首页 → 点击开始 → 生成种子和布局、加载本局资源 → 解码与场景/首批效果准备 → “开始这一局” → 计时与操控同时启用。加载失败可重试或返回。未知字节总量用阶段/资源数，不伪造百分比。核心资源在入局前就绪，重开复用已加载资源。

玩家出生时坐在本人工位，电脑里已经打开一段预写的豆包聊天。首轮镜头从肩后看得到屏幕，也能看到办公室；随时按E起身，不强制看完对白。聊天不是实时调用，不跳外部网站，不需要豆包账号。

## 3. 离场闭环：打卡，再出门

选择此方案的原因：找钥匙会增加独立收集流程；刷工时又回到坐等。打卡与找门提供两个清楚的空间目标，关键选择留给路线、遮挡、时机和规则利用。

### 3.1 打卡

- 员工出生自带工牌，属于随身身份，不占手持物槽；不用寻找或捡回。
- 地图固定两台可用打卡机，分布在行政前厅与另一公共走廊节点。任意一台即可。
- 距离≤1.2米、面向终端、直线无遮挡，且角色控制点处于前厅标明的明亮操作区，按住E 1.5秒。不能从墙另一侧或相邻暗室操作，滚椅同样适用。可转动镜头观察；移动、松开E或被抓取消未完成操作。
- 成功后“已打卡”永久保留到本局结束。被拖回、背锅、坐椅、领导发令均不撤销记录。
- 不广播玩家坐标。领导或同事只能通过实际目击该动作知道你准备离场。
- 打卡不显示出口位置；先找到门再回来打卡也允许。

### 3.2 出口

- 两个分离出口，都接受同一份打卡结果。未打卡时门把旁显示“未完成下班打卡”，不触发额外收集任务。
- 已打卡、距离≤1.2米、直线无遮挡且位于出口前室的明亮操作区，按住E 4秒打开重门；可观察环境，移动/松开则取消本次未完成操作。四秒是操作窗口，不是暗加的长任务。
- 打开完成后门保持开启，不再被领导远程反锁。玩家站立或坐椅越过外侧边界才结算。
- 人物身体不能永久堵门：双方接触会有可见让位/挤开，领导须主动完成抓捕才能阻止玩家。
- 打卡与出口前厅有明确可见的常亮应急照明，无可操作关闭开关。普通办公室可关灯。这个边界在房型外观和教程中说明，不把已经熄灯的房间偷偷判成亮处。

允许高手快速完成，也允许先探路再打卡；十分钟是期限，不要求每局强行耗满。新玩家预计需要探索和若干次周旋，此为体验目标而非已测局长。

## 4. 玩家操作与手感

| 输入 | 行为 |
| --- | --- |
| WASD / 鼠标 | 相对镜头移动 / 环视，近第三人称跟随 |
| Shift | 站姿冲刺；粘椅后用脚蹬地加速 |
| Ctrl或C | 站姿蹲下/起身；粘椅状态无效并有清楚提示 |
| Space | 站姿跳跃；粘椅不能跳 |
| E | 目标交互：坐下/离座、门、灯、打卡、拿纸箱/小饼；大饼为按住推行 |
| Q | 将自己的锅从背后/头上取到手里，再按归位 |
| 鼠标右键 / 左键 | 按住瞄准 / 投出手中物件；没有手持物时不触发攻击 |
| R | 轻放普通手持物；手持锅则归回背/头，不卸掉归属 |
| Tab / Esc | 查看手机规则与已知状态，局时继续 / 全局暂停 |

站姿步行3.1米/秒，冲刺4.8，蹲行1.6；跳高0.65米，不越过外围墙。滚椅普通3.6，蹬地4.4，不能蹲跳。冲刺/蹬地共用4秒额度，不加速时以每秒0.5秒恢复；耗尽只退回普通速度，不罚站。体力提示只在使用/恢复时轻量出现，站坐切换、受罚不回满。

持锅的所有移动速度乘0.85，拿在手里也一样。其他规则不得将玩家速度降为零；允许组合的平地速度下限为1.3米/秒。锅与压力/逆风的组合由同一移动公式计算，不重复乘到几乎不能动。

镜头默认约3.5米肩后、略高于人物视线；碰墙收近、不穿墙、不切成上帝视角。坐椅与蹲姿平滑调整镜头，不增加晕眩摆动。移动和取消操作不等待整段表现动画播完。

## 5. 装忙、目击与领导

### 5.1 领导为何抓人

领导把“六点后被他看见离岗”当作准备下班，想把员工留到18:10。程序依据看得见的行为判断，不能读取玩家心思、打卡记录或隐藏位置。

坐在可用电脑前时，玩家循环敲键盘、碰鼠标、观察门口；没有实际工作产出。未有明确证据时，领导看见装忙会降低注意，短暂停留后巡逻；仍可能宣布作用于房间或道具的正常规则。

普通离席走动被连续看见1.2秒后，出现注意提示并开始三秒预警。预警期间坐入可用工位或让墙/大饼遮断视线，可以取消本次普通离岗追责；没有明确事件证据时，追赶中连续装忙2秒也结束普通离岗追责。

实际打卡、操作出口门、朝人投东西是明确事件，连续看见0.2秒即可确认，不再叠加普通走动的1.2秒。坐下不能抹去已看见的事件；事件证据最多保留20秒，不反复因同一个事件刷新时限。领导不知道未目击的打卡事实。

### 5.2 视野、巡查与追丢

- 常规视野10米、水平约100度；墙、门与大饼遮挡有效。蹲下改变真实可见轮廓，不靠隐身概率。
- 正常巡逻2.0米/秒，追赶4.1。巡逻访问工位、通道、打卡前厅和出口前室；目标来自巡逻计划或已知事件，不追隐藏坐标。
- 三秒预警中领导可走近，但不能提前抓。普通离岗预警结束仍须目击目标，或已有未过期的明确事件证据，指令才生效。明确证据仍在但人已遮挡/进入暗室时，只调查最后位置，不能因此读取当前坐标。
- 当前追责有效期内再次看见目标可继续追，不每个转角重新赠送三秒；HUD保留“正在追责”的状态。
- 失去视线后只去最后看到的位置，搜索6秒。没有新目击则恢复巡逻；明确证据剩余期限仍在轻量状态中可查，期限内重新目击可继续执行同一已预警命令，不能隔墙追人。证据20秒上限不被搜索或坐下刷新。
- 无有效目击时同一点停留最多8秒，不能永久守一台打卡机或一道门。存在有效目击时正常追查，但仍要给玩家另一条路线。
- 不使用脚步、键盘声、投掷声音或听力范围获取信息。

### 5.3 抓回与粘椅

警告原话示例：“让我逮着，就回工位，屁股给我粘在椅子上。”追到1.1米内，连续保持视线和接触0.5秒、玩家在亮处且没有抓回保护，才实际抓住。通过把话写成有明确条件的规则，预警和闪避不会变成领导说过的话无缘无故不算数。

抓住后领导揪衣领，沿合法地面路线快速拖回本人工位，整个失控过程限定2—4秒，局时继续。镜头拉开少量跟随，所有拐角用路径平滑和连续碰撞处理；不穿墙、不用黑屏掩盖传送。拖行中不新增会封住该路径的规则。

本人座位周围保留0.9米半径落座净空及1.4米宽接入路径，放箱/推饼/动态变化不能占满，地面用普通工位边界表达。拖回前验证路径；意外无合法路线时领导先改道/将阻挡小物推到最近合法位置，不开始无法完成的拖行，也不能把人为堵座位变成永久免抓。本人桌被抬高时，回工位规则结束升桌并启动安全复位；椅位独立可用，落座不要求桌面先降到底。

落座后，前述已预警规则完成生效，透明栏显示“屁股不能离开椅子”。不追加一条未经预警的新指令。臀部与原椅粘住，**持续到本局结束**。玩家仍能移动、打卡、开门、操作开关、推饼和甩锅；不能蹲、不能跳、不能按E离椅。后来再被抓是连人带椅拖回，不叠加更重处罚。

回座后8秒再次抓回保护，领导转身离开本人座位至少8米再恢复巡逻，不原地连续抓。主动开始打卡、开出口或对人投掷会结束此保护，相关交互提示事先说明。保护不让环境规则失效，不能靠反复受罚获得长时间无敌。

## 6. 领导规则的完整协议

每次实际发令：明确对象 → 中上方原话与后果展示3秒 → 核验目标条件 → 生效 → 透明栏保留状态 → 明确结束或转为持久状态。手机可以回看原文。

“格局打开”的活动墙、更多话术、全楼停电、工资/好感数值和战斗不进入首版。这是明确范围，不是随机留待实现者选择。

### 6.1 发令节奏与冲突

- 全场最多两条临时空间规则，同一房间最多一条；锅归属、粘椅和追责是独立状态，不占空间规则名额。
- 相邻两次常规环境/分锅宣告至少18秒，同一类空间规则至少50秒不重复；首次追责预警独立于这个间隔，但同一时刻只展示一条完整宣告。正常环境发令窗口取24—36秒内的种子随机间隔；不按固定分钟强塞全套规则。
- 目击追责优先于尚未开始的普通宣告，已显示的三秒提示不被新字幕覆盖。新证据先可见记录，预警完成前不能抓。
- 领导不能一边全速追赶一边无限发令：发新环境命令时慢行1.2米/秒，维持到三秒宣告结束，再恢复追赶。
- 空间规则从合法目标选取。不能因为玩家躲在未知房间，就精准对那间房连续施压。
- 动态物件生长/下降前检查占位；恢复也使用连续碰撞。桌下降遇角色则停在安全净空，净空恢复再继续；显示复位受阻但不继续占用新的空间发令名额，同一未复位对象不再被重复选为升桌目标。不得夹死、把人弹到远处、堵住所有路线或将坐椅玩家困在无法通过的区域。若安全范围不足，本次取消并给可见反馈，不用坏布局换取演出。
- 第一条不利环境命令最早在玩家取得控制15秒后出现，给读开场和看周围的时间；不是15秒无敌，明确挑衅仍按规则处理。

## 7. 甩锅与物件

### 7.1 两口锅，一人最多一口

全局恰有两口锅，开局分别在两名坐着办公的同事头上；他们站立时才切到背后。背景是领导已经让他们承担项目责任；外观和简短气泡让来源可理解。锅不会按时间无限刷出，也没有自动消失的寿命。

玩家无锅时接触有锅同事，锅转到玩家身上；玩家已有锅则不转移、不互换。每次转移有2秒再次转移间隔，防止接触瞬间来回弹。正常同事不会远处主动朝玩家投锅。

站立附背，坐姿包括普通办公和滚椅时顶头。Q取出或归位0.3秒；手持、飞行、附着都计入同一份所有权，取下来不解除减速。一只手持槽，若已拿普通物先轻放到合法位置，位置不足则提示后保持原状。

### 7.2 投掷与结果

锅处于取放、飞行、贴附时不接受再次Q/R取放或再次投掷，不锁角色移动；命中只能结算一次。受抓时先把未完成的锅动作收束为回附，避免被拖走时锅仍沿另一条轨迹追人。右键瞄准显示短弧与当前可能命中的目标，左键投出，最大有效距离6米。投掷前摇0.2秒、飞行约0.35—0.65秒、命中贴附0.25秒；飞行沿路径检测墙和目标，不用点击人物名字直接传送。

- 命中无锅同事：锅从侧面绕到背/头，交接成功，原主人减速解除；同事本局记仇。
- 命中已有锅同事：不交换、不叠加，锅弹回原主人；仍被视为挑衅，目标记仇。
- 投空、撞墙：0.6秒内以可见弧线回归原主，归属与减速从未解除。不能随手扔地上永久卸锅。
- 命中领导：立即结束本局，显示“提前下班——明天也不用来了”。瞄准领导时提前标出“命中将被辞退”，不算正常下班成绩。
- 未命中但被领导看见朝他投：构成明确追责证据，仍有正常预警和抓捕条件。

可以一直背锅走，甩锅不是必做步骤。正常逃离保留背锅/滚椅状态到越过出口，不要求先清除惩罚。

### 7.3 其他物件

- 两个小纸箱：可拿、轻放、短距离投出，提供蹲姿遮挡或改变局部绕行。没有伤害和眩晕；被领导看见朝人扔会引发追责。
- 两个小饼：未变大时可拿放，与纸箱共用手持操作；变大后只能按E推，不能装进手里。领导也受其碰撞约束并可改道，不穿饼。
- 桌、门、灯、电脑、打卡机是固定交互设施；椅子由坐姿/规则控制，不提供任意拿走所有家具的系统。
- 放物必须有合法地面位置，不能完全堵住消防门和唯一通道；无合法落点就保留在手中并给出直观反馈。投掷普通物落地即静置，不做昂贵的长期刚体堆叠。

## 8. 同事：固定工位，有限而可读的关系

四名同事分布在三个工位区。都在自己的位置办公，有抬头、看向、拿手机、抱怨等表现，不做自主漫游、交易或复杂日程。

两名开局背锅；其中一名位于出生工位可见的邻座，保证玩家能看到机会，但不挡必经门框，不强迫中锅。另两名空背，可成为转移对象。关系只有正常/记仇，不显示好感数值。

正常同事不举报普通走动，近距离看见打卡/开出口或朝人投掷才举报。记仇同事还会举报离座经过的玩家。归责不因锅后来转走而消失。

同事视野5米、约100度，只在亮处、无遮挡并连续看见1秒后认定。抬头和拿手机是可见预兆；10秒后把**当时看到的位置**报告领导，每人每25秒最多一次，同一目标一名同事最多一条待发送报告。此后躲开不会删除已经发生的目击，但不会持续上传实时坐标。

领导把报告作为调查目标，不瞬移、不立即进入已知玩家位置的追逐；到达后仍要重新目击。暗处同事无法识别新事件，已发生的报告不被关灯取消。

## 9. 灯与黑暗

普通工作房、会议室、茶水间、打印区、储物间有各自墙面开关；双方都须到距离1.2米内操作。切灯0.25秒，同一开关操作后4秒复位期，按钮和小指示灯清楚显示，防止同地点无限闪灯。

玩家处于熄灯房间时，领导不能开始或完成抓取，包括抓取0.5秒的中途熄灯。三秒追责预警未完成也可借黑暗脱离。已经完成抓取、进入拖回的过程不被途经暗房反向取消。

黑暗不删目击证据、不解除粘椅或锅；领导可沿已知信息走进房间亲自开灯。开灯后还须满足有效追责、视线、距离和抓取时间，不能同一帧瞬抓。

公共打卡与出口前室保持应急照明；普通暗室可以装忙、躲避、观察、铺撤退路线。没有“灯灭不能累计工时”之类已废除门槛。暗室不黑成全屏，保留人物、门与开关轮廓；安全判定由房间真实状态决定，UI给出“暗室保护”。

## 10. 随机地图的固定设计规格

单层、约48×36米包围范围、10个房间模块：三个工位区、会议室、茶水间、打印区、储物间、前台、行政区、领导室。门的位置、模块连接、打卡点具体节点、出口对应外墙、道具与同事分布随种子变化。房型和通路规则由Codex设计，Kimi只按尺寸做外观。

- 至少两条跨区域回路和两条横向连接；出生区、打卡点及出口不能共用一个唯一瓶颈。
- 出生到最近打卡机至少跨三个房间连接且可走距离≥24米；出生到最近出口可走距离≥45米。任一打卡点到最近出口至少跨两个连接。
- 两出口最短步行路程≥50米；每个打卡点至少两条可进出路线，两台机器不能放同一房间。
- 门净宽≥1.4米，主通道≥1.8米，常规门净高≥2米；所有必需目标有站立与滚椅都能走通的路线。
- 两处0.95米高的可选检修短道只供蹲姿使用；不是必经路线。椅子失去这些捷径，仍能绕行完成。
- 不做线索谜题、出口箭头导航、未探索全图或自动揭露门位。房间牌、打卡机、真实出口外观近距离可辨，避免十扇完全相同的门纯靠试错。
- 生成器先生成连接图再放家具和视觉。每局验证出生、两台打卡机、两出口、各明亮操作区、本人落座净空/接入通路、开关、滚椅、动态规则范围与替代路线；最多尝试20个候选，失败用已验证备用种子。
- 不保证数学意义上永不重复的办公室；同种子复现初始布局、对象和巡逻随机序列，玩家不同动作仍会产生不同遭遇。

## 11. 普通难度与公平边界

难度来自有限时间、未知路线、可见对手、持续代价和空间变化；不是隐藏任务、永久丢进度或全知追踪。只做一档普通难度，避免六小时内同时调三套配置。

必须成立：

1. 玩家能在三秒预警里做出有用反应；明示行为与普通走动的目击时长不同，不能当着领导面稳定利用固定窗口开门。
2. 持续按Shift不能永远绕圈甩开领导；冲刺额度迫使选择遮挡、关门或黑暗，但耗尽仍能移动。
3. 被抓一次仍有机会赢；已打卡不清零、椅子可走全主路、回座有防连抓窗口。不能靠抓回无敌反复强行操作门。
4. 锅只减速15%，可以带锅通关；锅与其他状态组合不会让角色挪不动。
5. 两出口和两打卡点是真正分离的选择，领导追丢后不凭空知道你改走哪条。
6. 切灯、蹲行和提前探路可以形成有效策略；不是为了追求难度把所有玩家聪明办法都禁掉。
7. 连续高压之后允许搜索失败、巡逻与装忙产生喘息；不会每几秒再叠一条惩罚。

默认预期新玩家有若干探索和周旋机会，熟练玩家明显变快。六小时内的小样本只能发现重大问题，不能宣称统计平衡或所有玩家都觉得好玩。

验收专测：无脑跑步直出、开局关灯不动、当面打卡/开门、一直切灯、反复坐下洗追责、故意受罚借免疫、双出口守点、锅无限弹/复制、坐椅卡门和低顶卡住。若太简单，先改巡逻覆盖/视线与目标布置；若太难，先减少同一时间的干扰和追责持续。不得取消明确反制、重置打卡成果或偷偷添加钥匙。

## 12. 一局的两个实际选择片段

这是按规则推演的示例，不是固定时间刷事件或已试玩记录。

**先探路的人：**18:00从工位起身，邻座背着锅。玩家绕开他，穿过茶水间，看到一扇出口但尚未打卡。回头发现领导在玻璃后，蹲过检修口绕到行政前厅。打卡1.5秒时领导转头，玩家选择完成打卡再跑，拿到永久成果但留下明确证据。冲刺快用完时关掉会议室灯，从另一门走。以后即使被拖回，也只需设法再到出口。

**贪一手甩锅的人：**碰到同事继承锅，玩家先装忙等领导离开，再取锅投向另一位同事，减速消失，对方却记仇。后来经过时被目击，10秒后领导调查旧位置。玩家误以为坐下能清掉打卡证据，被追近拖回；现在粘着椅子。路线改为主通道，不能钻之前的矮洞，却能从“低头扛压力”的低顶下快速滑过。找到出口后仍需判断能否安全完成四秒开门。

两条路线都以打卡与离场为目标；不要求体验所有规则，不给每个人安排同样的解法。

## 13. 动作、工具与制作分工

Codex负责所有内在：胜负、参数、操作、地图模块与生成、对手、碰撞、导航、规则组合、UI绑定、实际整局试玩与流畅度验收。

Kimi负责外在：首页与全套UI、角色/场景/道具外观、配色材质、动画姿态与动效表现。Kimi不设计游戏机制或房型模板，不决定判定，不承担整体游玩/平衡/性能测试。实际画面的美术复核仍属于Kimi职责。

最新分工：Kimi Work独立主导完整视觉设计、制作与监督，由Kimi调用Tripo官方CLI/API生产视觉资产；旧双方调用及Codex代生成安排撤回。Codex继续内在程序、接口与集成，最小灰盒不预定成品外观。用户授权的Kimi提示词库由Kimi自行选参考，办公室案例仅是可参考素材，不是指定视觉风格。详见[分工纠正](../CODEX_VISUAL_REFERENCE_ADDENDUM.md)。生成模型、骨骼、动画、可用挂点、已接入和真实动作通过是不同完成状态。详见[工具与资产调用](工具与资产调用.md)、[Kimi简报](Kimi美术与UI简报.md)。

以下姿态是历史表现示例，具体动作设计由Kimi Work独立决定，保留对应玩法语义：取锅时耸肩、投出时小幅前探、锅绕身贴附、同事愣一下再瞪眼、领导揪衣领快步拖回、屁股粘椅后挣扎起身却连椅提起一点、脚蹬滑走。人物仍可迅速移动/取消普通操作，受抓阶段以外不因动作演出长时间锁控制。

布局碰撞由简单代理体表达，表现模型可替换；骰子式生成整张不可控3D办公室不进入管线。墙门与机关按尺寸制作，Tripo用于角色和少量关键道具，Kimi可用程序补外观。

## 14. 六小时与最终交付

一个用户独立制作、依靠AI工具，零真人队友产能。首版实施按[制作计划](../tasks/plan.md)和[任务清单](../tasks/todo.md)，保留最后90分钟做公开版本试玩、修复和交付。

网页发布到已选GitHub Pages，使用现有公开仓库，不购买域名或服务器。每位访客在各自浏览器玩独立单人局。未来联机再独立设计服务，这次只在首页如实标待开发。

首轮默认画质目标、设备记录和帧节奏标准沿用[上线与流畅度验收](上线与流畅度验收.md)。公开网址可访问、完整通关、动作手感与运行流畅分别验收。设计完整不代表六小时工作量已被证明、或资产/动画已成功；出现真实不足要修复并明确记录，不能用假动作或自动播放冒充。
