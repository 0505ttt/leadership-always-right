## 2. 已复现的实现偏差

### P2：最后不足一帧仍获得整帧移动

位置：`src/rules/game.ts:37`、`:59`、`:61`。时间先封顶600，但仍用完整dt更新移动、检查逃出，最后才处理overtime。

实际生成地图618中，已打卡且出口开启，玩家距越界阈值尚差0.04米，elapsed=599.999、remaining=0.001。调用一次1/60秒更新后，前进0.05167米，结果是elapsed=600、remaining=0、ending=escaped。剩余1毫秒的真实移动不足以跨越边界。

建议只模拟本局剩余dt，明确最后一步的结局时序，补“最后不足一帧不能多获得整帧距离”回归。现有600秒测试只覆盖站定超时，没有覆盖最后一步跨线。

### P2：近墙投物占点后长期悬空且不可再次拿起

位置：`src/rules/objects.ts:190`—`:192`，及 `legalDrop` 的单一朝向搜索。原预留点被角色占用后，备选位置只沿玩家正前方搜索；近墙时全在墙外，`if(!spot)continue`持续重试，飞行状态不会清除。候选交互也排除了正在飞行的物体。

实际生成地图618：玩家 `(2,33.1)`、yaw=0，手持纸箱投出，预留落点为 `(2,35.3)`。立即向前冲刺34帧后停在z≈35.58，再原地120帧，纸箱仍位于 `(2,35.3,y=0.16)`，`propFlights`仍有该纸箱。背后存在可用地面，但搜索没有尝试。玩家离开/转向可能使重试恢复，不是断言整个游戏永久锁死。

建议落点附近做有限的多方向安全搜索，或提供明确回收策略，并补这个实际边界回归。已有“演员进入落点”测试只用了开阔空间，没覆盖贴墙无前向备选的位置。

### 证据倒计时接口：审查中已补，展示待接入

8954d87的UIModel没有事件证据剩余秒数，Kimi无法从规定的只读UI接口展示V3 §5.2要求的剩余期限。本审查反馈后，父任务已在当前工作树新增 `bossEvidenceRemaining`，绑定为 `max(0,evidenceUntil-elapsed)`。这是接口修复，不等于正式UI已显示或已验收；需随Kimi交付接入。

## 3. 需要补齐的验收与测试

重要：给分锅、逆向阻力、透明隔断、压力各补一条完整生命周期行为测试，并覆盖“预警中条件变化取消”“两条空间规则上限/同房冲突”“至少18秒间隔/同类50秒间隔”“拖回中不发封路规则”。这些测试应断言状态、碰撞/视线/速度和恢复结果，不能只断言规则名出现。

重要：使用真实输入验证当面打卡/开门、反复坐下洗证据失败、不断切灯的复位限制、主动操作解除抓回保护、粘椅并背锅仍能正常离场。它们是V3难度和公平性的专测，不能以知道全图的33.87秒自动通关代替。

重要：在最终公开commit验证全部三结局、三次重开的资源/监听稳定性和第二浏览器基本进入；累计10分钟正式候选有效运行并覆盖追逐、抓拖、首次及并发规则。现有30FPS空白页/游戏对照只证明该自动浏览器的环境基线，不能证明58FPS目标通过。截图附近196.5ms长帧需保留和复验。

建议：补八米离开过程、保护被各明确行为解除、25秒举报冷却/单待发限制，以及异常阻挡下拖回路径恢复用例。当前无路抓回只提示改道并拒绝开始，没有实现V3文字中“必要时推开阻挡小物”的分支；现有生成与摆放限制降低了触发风险，本审查尚未复现合法正常操作造成永久免抓，因此登记为未覆盖降级路径，不称为已证实主线阻断。

正式首页、教程、手机、开场对话、规则目标/倒计时可读性、独立UI/角色/场景预览、表演动作及视觉复核仍需Kimi交付与集成。当前技术占位不算这些项目完成。
