# V3制作执行清单

更新：2026-10-30。全部待执行，当前没有游戏实现或生成资产。采用[V3完整玩法](../docs/单人完整玩法提案-v3.md)后执行；[计划](plan.md)给预算与验证方法，不把文档勾成代码完成。

## T01 契约与接入（0—20分）
- [ ] 确认本轮采用的V3；把唯一状态、输入、事件、碰撞尺寸写入共享契约，无工时/电脑任务字段。
- [ ] 核查远端仓库/Pages权限，保留内容，不强推；检查Kimi/Tripo实际登录与API额度。
- [ ] 按资产ID与文件范围分配所有权，建立来源/任务ID记录；不重复生成。

## T02 移动与高风险动作灰盒（20—70分）
- [ ] 近第三人称、走跑蹲跳、冲刺额度、镜头碰墙、输入焦点可用。
- [ ] 坐椅移动/加速、不能蹲跳、快速合法路径拖回与落座，粘椅本局持续。
- [ ] 门/灯/物件代理可交互，早测帧节奏，Kimi并行首页/HUD及角色表现。

## T03 单局目标与第一次上线（70—120分）
- [ ] 18:00本人电脑预写豆包彩蛋与装忙，没有工时和电脑文件任务。
- [ ] 两台打卡机、两出口；未打卡不得离场，打卡永久，开门后实际越界结算。
- [ ] 正常下班/超时/被炒三结局，600秒、暂停/恢复、种子重玩和新局互不残留。
- [ ] 首页/教程/加载/重试/明确禁用的多人待开发；资源准备后才计时。
- [ ] 最迟120分钟完成一次真实Pages构建与资源路径验证。

## T04 领导、锅与同事（120—170分）
- [ ] 视野/遮挡、普通走动与明确事件、三秒预警、追丢查旧点、装忙不洗明确证据。
- [ ] 亮处近距抓取、暗室中止、拖回、防连抓及主动挑衅结束保护；不穿墙/不听声/不全知。
- [ ] 两口锅、一人一锅、站背坐头、手持仍减速、投空回主、已有锅不换、领导命中特殊结局。
- [ ] 四同事固定办公、接触转锅、记仇、目击延迟10秒报告旧位置及频率限制。

## T05 规则与恢复（170—210分）
- [ ] 画饼、升桌、分锅、抓回粘椅、逆向流程、透明隔断、低头压力七类真实规则。
- [ ] 三秒预警/目标/透明状态栏，常规与追责时序不冲突，环境名额不被锅/椅占满。
- [ ] 视觉/碰撞/视线/导航同源，生长/下降/恢复安全，所有允许组合仍可行动。

## T06 随机地图（210—240分）
- [ ] 十模块、双机双门、回路/横联/距离/净空、可选蹲洞与滚椅主路。
- [ ] 普通房可切灯，公共前室可见常亮；开关复位期、门前/放物不产生死锁。
- [ ] 多种子可达/恢复检验，同种子复现；20次失败回退已验证布局。

## T07 外观与全页面集成（240—270分）
- [ ] Tripo资产/骨骼/动作/挂点逐项验证，办公/投锅/吸附/抓拖/粘椅自然可读。
- [ ] Kimi Work完成视觉设计、制作与持续美术复核，并负责Tripo生产；Codex做内在程序、集成与玩法/平衡/性能验收；工具参与有真实记录。
- [ ] UI/角色/场景独立预览复用正式组件；五秒抱怨气泡与三十秒冷却不吞领导宣告。
- [ ] 270分钟停止新增功能和模型，公开候选包含全部必需链路。

## T08 验证与修复（270—335分）
- [ ] 相关规则/归属/胜负/地图自动检查、构建与typecheck；不做镜像实现的伪覆盖。
- [ ] 三种子各三段开局＋两场完整对局；清楚区分片段、自动和人工结果。
- [ ] 检查无脑跑、当面开门、暗室挂机、切灯、洗证据、免疫套利、守点、锅重复、滚椅/顶板死锁。
- [ ] 记录难度原因并调参，保留预警、打卡成果和有效反制；重大缺陷优先于装饰。
- [ ] 在公开候选记录帧率/帧间隔尾部、拖回/首次规则/重开，另查镜头与操作。

## T09 最终发布与交付（335—360分）
- [ ] 最终commit与Actions/Pages成功；未登录打开实际网址，构建版本与测试对应。
- [ ] 最终候选累计10分钟有效运行；目标1080p默认平均≥58FPS、P95≤20ms、P99≤33ms，无可重复100ms游戏停顿，未达标如实记录。
- [ ] 三次重开不恶化；另一浏览器做启动/输入基本检查，未覆盖环境不虚称通过。
- [ ] 交付公开链接、仓库/commit、操作说明、真实难度/性能结果、资产/Kimi记录、本地备用与评委短介绍。
- [ ] 不自动给评委发消息，不购买服务器/域名，不用构建通过或30FPS冒称完整畅玩。

权限与生成额度、模型质量和实测性能按真实状态记录；当前所有生产任务未执行。
