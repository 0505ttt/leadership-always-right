# 主集成锁定规则（2026-10-31）

用户已指定当前 Kimi 主集成会话统一负责程序、主入口、场景、规则、碰撞与最终整合。

- `src/main.ts` 的默认生产流程固定为：**启动 → 真实预加载 → ready → 统一首页 → 开始上班立即开局**。
- 默认入口必须使用 `design/entry-experience` 已交付的统一组件。不得再改成 `preview==='entry'` 才可用的实验，也不得恢复旧 `createLoadingScreen` 作为默认或并列封面。
- 首页“开始上班”不得再次调用 `loadGame()`；不得重新生成种子或重复下载已 ready 的资源。
- `visualAssetsReady` 只能在正式场景装配、路线验收、纹理上传与着色器准备全部成功后置真。
- 旧加载模块仅服务其独立预览，不参与主流程。手机正式玩法使用横屏，不使用竖屏游玩。
- 其他首页、房间美术、验收会话不得直接修改 `src/main.ts`、游戏规则、地图、碰撞、共享资源清单或主场景。需要变更时提交补丁或接口要求，由主集成落入。
- 不回退他人已交付的视觉组件、未提交素材和验证证据；不把独立预览当成主游戏接入或整局验收。
