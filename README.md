## 本地运行

Node.js 22.12或更高版本。

```sh
npm ci
npm run dev
```

浏览器打开终端显示的 `/leadership-always-right/` 地址。生产备用：`npm run build` 后 `npm run preview`。无需后端或运行时AI服务。

房间美术独立预览入口为 `/leadership-always-right/room-decoration-preview.html`，提供十房正常视角、标牌与材质近景、总览和连续巡房；接入及实测说明见 [房间装饰独立交付](docs/kimi/handoff-room-decorations.md)。

## 操作

WASD移动，鼠标环视，Shift有限冲刺，C/Ctrl蹲下，Space跳跃，E交互，Q取锅/归位，右键瞄准/左键投出，R轻放，Tab手机规则，Esc暂停，F使用电脑。手机使用画面触控按钮与双指走看。单人600秒期限，自带工牌；打卡1.5秒，开出口4秒，走出门外才算下班。粘椅本局持续但仍可移动和交互。多人待开发。

## 制作分工

Codex：机制、地图、程序、输入镜头、集成、完整试玩与部署。用户手动启动的Kimi：整体审美、UI、角色/场景/道具、动画姿态、按资产ID自行使用Tripo及美术复核，通过 `docs/kimi/` 交接；没有将普通Codex代理冒称Kimi。Tripo离线生成资产，任务与实际成本见 [资产台账](docs/production/资产台账.md)，客户端无生成密钥。

正式资产、角色动作、房间装饰和加载封面的交付与来源记录位于 `docs/kimi/`；本地接入不替代 Kimi 对最终主场景的美术复核，也不把程序代理称作 Kimi。

## 检查

`npm test` 验证规则不变量与地图路线；`npm run build` 包含TypeScript检查。公开试玩、真实手感、难度与帧节奏需要单独实测，并记录最终commit，不由测试数量代替。
